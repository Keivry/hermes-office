## Layout Guidelines
- Every slide needs a visual element (image, chart, icon, shape)
- Vary layouts across slides (columns, cards, callouts)
- 0.5in minimum margins
- Left-align body text; center only titles
- Dark backgrounds for title + conclusion slides; light for content

## Common Mistakes to Avoid
- Repeating same layout across slides
- Defaulting to blue — pick topic-specific colors
- Creating text-only slides
- Using accent lines under titles (hallmark of AI-generated slides)
- Low-contrast text/icons
- Neglecting subagent visual QA
