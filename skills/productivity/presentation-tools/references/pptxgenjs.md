# Creating Presentations from Scratch (pptxgenjs)

Use pptxgenjs (Node.js) when no template or reference presentation is available.

## Install
```bash
npm install -g pptxgenjs
```

## Usage
Create a Node.js script that builds each slide using the pptxgenjs API. Each slide defines text boxes, shapes, images, and formatting programmatically.

## Tools Available
- python-pptx (Python): for programmatic creation with more complex logic
- pptxgenjs (JS): simpler API for straightforward presentations
